# Code of Conduct

This is a small project, so this is a short document.

## The rules

Be decent to people. Assume they're acting in good faith. Criticise code, not
the person who wrote it.

Not welcome here:

- Harassment, insults, or personal attacks
- Sexual language or imagery
- Publishing someone's private information
- Sustained disruption of discussions

That applies to issues, pull requests, commit messages and anywhere else the
project is being discussed.

## Disagreements

Technical disagreement is fine and useful. "This approach is slower than X, and
here's why" is a good comment. "This is garbage" is not. If a discussion stops
being about the work, it's done.

## Reporting

Report problems by [opening a private security
advisory](https://github.com/c4ist/nex/security/advisories/new), which is only
visible to maintainers. Use it for conduct issues as well as security ones. If
the problem is public and obvious, an issue works too.

Reports are read by the maintainer. Depending on what happened, the response
might be a warning, having comments removed, or being blocked from the
repository.

## Scope

This covers the repository and any project space. It doesn't extend to what
people do elsewhere, unless it's directed at someone here.
